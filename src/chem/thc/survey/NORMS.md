# THC embed norms: all materials, all checkpoints

Machine-readable companion: `all_materials_norms.csv`.

## The three norms

All share `max_Q ||W^Q||_op` and differ only in how the two collocation factors
are measured. `||A||_(2->inf) = max_I ||A_(I,:)||_2`, the largest row 2-norm,
maximised over `k` as well, evaluated in the `(k, I, p)` basis.

| column | formula |
|---|---|
| `alpha_op` | `(max_k \|\|X^{o,k}\|\|_op)^2 (max_k \|\|X^{v,k}\|\|_op)^2 max_Q \|\|W^Q\|\|_op` |
| `alpha_mod_v` | `(max_k \|\|X^{o,k}\|\|_op)^2 (max_{k,I} \|\|X^{v,k}_{I,:}\|\|_2)^2 max_Q \|\|W^Q\|\|_op` |
| `alpha_mod_o` | `(max_{k,I} \|\|X^{o,k}_{I,:}\|\|_2)^2 (max_k \|\|X^{v,k}\|\|_op)^2 max_Q \|\|W^Q\|\|_op` |

Since `||A||_(2->inf) <= ||A||_op`, both modified norms are `<= alpha_op`.
Neither modified norm bounds the other in general.

## Caveats

- Absolute values are in the checkpoints' internal units; only ratios are dimensionless.
- Families are not comparable to each other. Only `ISDFov_opt_*` was optimised against
  a norm at all (and against `alpha_op` specifically), so its values are far smaller.
  The `ISDFfull_*` families were never fitted for the ov block, so evaluating an
  ov-block quantity on them is valid arithmetic but not what that fit optimised.
- Neither column is monotonic in `c`. `generate_isdf_gdf*.py` selects its
  regularisation independently per run by a 1.5x-error stopping rule, which breaks the
  underlying trend. Do not read rank scaling off these columns.
- None of these is a validated LCU lambda for a circuit; the `4/n_k` prefactor in
  `bse_thc.py:apply_V_thc` is not folded in.
- jsun3's data was read only; nothing under the source tree was modified.
